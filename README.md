## A little about the journey

I didn't start out writing AI systems.

I started with **design**.

That eventually turned into web development, then backend development, then machine learning — and eventually led me into Generative AI and agentic systems.

Each step taught me something different.

- Design taught me to care about how people experience technology.
- Backend taught me how applications actually work underneath.
- ML taught me to think about data, models and evaluation.
- GenAI taught me to think beyond individual models and towards systems.

And now I'm particularly interested in what happens when all of these pieces come together.
